# Custom feature log

When a change in this repo adds or alters a feature — anything a user could notice — append **one
line** to [`CUSTOM-FEATURES.md`](./CUSTOM-FEATURES.md) under "Added in this repo", in the same
commit. One line maximum, written as what the user gets. Skip it for refactors, tests, docs, build
and dependency work, and for anything that arrives by mirroring or merging `frbarbre/orca` or
`stablyai/orca` — that work is not ours to log.
